# Configurable Fluid Dump (Discharge)

A standalone Timberborn 1.1 mod that lets you configure the flow rate of the Fluid Dump (Discharge) in **Mod Settings** without requiring additional bottled water inputs.

## Features

- **Water Flow Multiplier**: Multiplies the clean water discharge flow rate (Game default: 1x = 0.6 m³/h). Consumes the exact same input ingredients (e.g. 3 bottled water).
- **Badwater Flow Multiplier**: Multiplies the badwater discharge flow rate (Game default: 1x = 0.6 m³/h).
- **Allow Submerged Dumping**: Optional toggle to keep fluid dumps dumping even if the water below has reached or submerged the spout.
- **Dynamic Updates**: Mod Settings take effect live without restarting the game.

## Requirements

- Harmony (v2.3.3+)
- Mod Settings (v0.6.5.1+)
